線性篩

線性篩的想法是想辦法讓範圍內的合數都只被其最小質因數篩到恰好一次

vector<int> primes;
for(int i = 2; i <= n; i++) {
	if(!sieve[i]) primes.push_back(i);
	for(long long p: primes) {
		if(i*p > n) break;
		sieve[i*p] = 1;
		if(i%p == 0) break;
	}
}

若i⋅pi \cdot pi⋅p的最小質因數不是ppp而是qqq，則q∣iq | iq∣i，由code可以發現一定在更之前的迴圈就跳出了
故這樣複雜度能夠保證是O(n)\mathcal{O}(n)O(n)
