# 適應

某個日子突然有一種自己是不是適應工作了的感覺。
或者應該說我適應我的不適應了。

我覺得我永遠都不會習慣每次開會或是討論總是提到一堆我一點概念都沒有的三或四字母縮寫。
但我的理解是也不需要聽懂每個人在幹嘛，只要自己報的有讓至少一點人聽懂就好了。
<!-- corp speak 還不會講但聽了很多 -->

來談談工作。
每次別人問我工作是什麼總是感覺很難回答。
最近接了某個 block 的 owner。精確來說是和 manager 一起。
所以說那個 block 相關的 bug 就有機會會 assign 到我身上。前幾個禮拜還蠻多的，一直有事做。
但解 bug 的流程又是怎樣？感覺我依賴 LLM 的程度越來越可怕。
bug 來第一件事就是先丟給公司內部的 AI。不趕的話就喝杯茶滑個手機，等他跑完結果我再來解讀他講了什麼。
上 code 或是 commit message 也直接叫他 push。
雖然還是有要看 code 但我已經好久沒有手寫程式碼跟手動 debug 了。我手動改了程式碼以後還要知會他讀進 context 裡面很麻煩（？）
把常做工作的 context 都丟到長期記憶裡面，那些偏 routine 的格式工作或是找 context 的速度就越來越快。

在 LLM 以前，我曾經有一個想像是打競程給我的價值是我寫出正確的 code 很快、我能記得完整的執行流程、我能抽象出程式碼 pattern 並好好封裝，但一方面是 codebase 真的很大[^bigcodebase] [^cleancode]，一方面是 LLM 真的 80% 的情況都做的比我快又好，一方面是一直 delegate 給 agent 做自己的能力感覺也一直退化。感覺我的記憶越來越差。

<!-- 每天都在公司信看到一堆 AI 味的不論是圖或是文字，我感覺審醜疲勞了。 -->

[^bigcodebase]: 話說最近有一個話題是說 AI 公司因為 git 沒辦法處理 100G 之類的 codebase 所以自己研發版本控制工具，我們的 codebase 動輒兩三百 G 底層也是 git（有用 [repo](https://source.android.com/docs/setup/reference/repo?hl=zh-tw) 就是了，但 repo 也只是一個 git wrapper）
[^cleancode]: 又想到我們的 codebase（google3 可能也是）有兩種操作我覺得很沒美感但好像又只能這樣做，一個是直接把 binary commit 進 repo；另一個是有一堆專門用來 generate code 的 script，感覺就很不符合 "The important part is moving program logic away from hardwired control structures and into data."

現在感覺對我來說人的 effort 變成

1. 找到問題問 AI 做事
2. judge 他的結論到底是對的還是錯的。可能是獨立問了很好幾次 LLM 這件事是不是對的一直更新自己心中的 Bayesian，或是對於能直接跑一次 deterministic code 就能成功的事情照著做看是不是真的。
3. judge 他生的 output 好不好讀，叫他改。特別是最近的 model 常常寫很多正確但沒什麼用的廢話，直接丟給別人大概很降低溝通效率。
4. 尋找 spec、文件或是任何相關的 context 丟給 AI
5. 釐清哪個是 source of truth
6. 對成品程式碼的美麗程度吹毛求疵
7. 跟其他人類直接溝通，推進不論是 verify 或是 fix 端的進度。或是我實在沒辦法 judge/理解 AI 在說什麼的時候去問 manager。常常覺得我的 manager 太扛了，感覺很多硬體互動的流程都倒背如流（？）spec 也是。總覺得我永遠都做不到那樣子。
8. 理解 AI 寫的東西或是講的話（因為需要跟其他人類直接溝通）。

想起來校內賽我有幫忙「出題」-- 有一句話出題的點子然後我要把他出成包含測資、官解、題敘等資料。結果我丟給 codex 大概 10 分鐘就生完所有東西了，我也沒有跟他說該怎麼解這題。雖然後續還有叫他修一下題敘、補一些複雜度介在臨界的解，但基本上很難不覺得自己沒價值。btw 我現在感覺好難找到自己的優點，不論是拿來寫在履歷上的或是人際關係上的。

講到 AI，我其實手上除了解 bug 以外的工作可能就是搞 AI。但一點機器學習的元素都沒碰，現在在做的事是接頭 agent 在我們的 bug 上讓他自動 reproduce/investigate。除了很難 judge 他做得好不好以外，感覺也並不是一個多有智慧的 project。就有一種感覺是這個 project 大概在我心目中的歧視鏈最底端（？）端出一個雞肋 slop 但我得把他講的多不錯，才能增加作為一個 artifact 的價值。講到這個就想到前陣子 present 我們的 skill，實在沒有什麼內涵可以講，然後就在那邊用英文講一堆沒人在乎的 technical details。

~~常常在想追求這些目標到底有什麼意義，把「想要錢」當作一個終極目標感覺也不是那麼有意義。~~
我不知道該在乎的是什麼。也許該找個女朋友但蠻有難度的。
我們 team 好常一起去吃飯（公司內）。吃飯總是會有聊天。聊跑步？聊健身？聊旅遊？聊球賽？聊股票？在當下不感興趣的話題我常常都心不在焉，但又有一種不該都不講話的感覺。就覺得自己很空洞。中身がない。
話說又想到一件事。雖然人是會變的，但有時候我說過但後來沒有照做的話都有點在心中毛毛的。
舉個例子像是之前晚餐的時候想說喝一下牛奶，別人問是不是喜歡喝我說是但後來幾乎都沒在喝。或者是以前可能說我不太想運動但最近又跑去爬山還健身之類的。感覺我的行為本來就很隨機又矛盾，只是腦裡講話的部份會強行給他安一個理由。這樣一看感覺自己就很 LLM。所以聊天好難。

我的工時越來越短了。
不知道該說我臉皮薄還是厚，現在差不多是十點多吃完早餐走到座位上，基本上沒有超過五點半下班。
最近 WFH 的兩天大概就是軟爛。會起來看訊息跟收信，但不會跟辦公室日一樣打開好幾個 LLM session 一直找事做（ADHD simulator）。
bug 不是已經沒有我這方可以做的事卡在 user/vendor 身上或是就是很難推進（怎麼看都需要大量 refactor 才能解的問題）。

其他人感覺好多會要開，但我幾乎沒有。每次聽到 team 上的人在哀怨要開好多會就覺得我今天根本沒 meeting 是不是有點太躺平（躺平好）。
雖然一直在抱怨該換工作，但聽了一些其他人的情況開始覺得事情是一體兩面的。
隔壁或是其他公司那些聽起來感覺好像比較有趣的事情常常都有一些什麼有很硬的 deadline 或是需要 on call 的事情；而我目前我覺得我這樣可以一直有很多很閒的時間（也許畢竟我是小 L3？）而且我可能也不太想換去一個要花很多時間的工作。

想到前幾個月 ramp up 有多難我就覺得換工作麻煩。我真的是一個很怕陌生人的人（我不知道為什麼）。但我也是真的對這些硬體的東東興趣缺缺 -- 前幾天才在會議上有人分享了 boot 流程那些 SoC 裡面的硬體會有哪些互動的一個教學網頁，但我還是覺得看了就頭暈。以最終目標來說，我們 team 是為了弄出 pixel 在工作，但以目前產品在大家的評價來看 pixel 真的不知道有沒有未來，而且我們做的事情更間接，都不知道幾年後才會有我的 code 造成的因果關係傳播到一台手機上。

回頭一看，發現自己還是講了好多工作的事情。工作以外就沒生活了嗎？我有一位家人每天回來都會一直滔滔不絕他工作又怎樣怎樣，讓我覺得很不想成為那樣的人，但可能還是沾染到這種氣息。

雖然我想寫下很多我的原則，但我覺得我實際上也沒那麼多原則。
在通勤或是平常一些碎片的時間都會在心中想一些我想主張的事，但在心中想著這些東西但自己打字跟整理成文章的速度都好慢。
感覺自己應該多寫點短文更新部落格，但每當有空閒的時候太多事情可以抓走我的注意力了。either 打音遊，看小說，玩魔術方塊或是看影片（e.g. QuizKnock）時間就徒然的過去了。整理房間或是寫部落格都遙遙無期。今天趁颱風假寫完了。

不知道怎麼樣減少我的 friction。
也許真正的方法是我該用個 TTS 然後用講的。或是用手機好好搞一下跟電腦的 sync。
